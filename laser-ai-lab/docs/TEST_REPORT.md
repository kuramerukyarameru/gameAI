## ブラウザ検証の方法と範囲

この作業環境ではブラウザのURLナビゲーションに制限があるため、Chromiumに同梱のHTML・CSS・JavaScript・Wasmをメモリ上のアセットとして読み込んで検証しました。ブラウザ側のWorkerは検証用に同じソースをまとめたclassic Workerを利用しています。**配布物のWorkerはES Module Workerのまま**です。

配布する `js/worker.js` 自体は、NodeのWorker環境アダプタから変更せずに読み込み、実際のWasmを使った対局・先後ペア・再現性を別途確認しています。

GitHubアカウントへのアップロード、GitHub Pagesの実URL上での確認、GitHub Actions補助ワークフローの実行、Safari / Firefox実機での動作確認は行っていません。公開後に、利用する環境でHTTP配信・Worker起動・公開パスを最終確認してください。

## 実験値について

ブラウザの動作確認用20局では、AI02が18勝2分0敗となりました。これは特定の実験シード・10盤面の**動作確認用の観測結果**であり、一般的な強さや最適性の証明ではありません。配布サイトの初期画面にはこの数値を埋め込んでいません。

実行時間は端末・ブラウザ・負荷・計時精度に依存するため、固定の処理性能や1局あたりの所要時間は保証しません。
