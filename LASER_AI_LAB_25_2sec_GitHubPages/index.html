04 / FIELD GUIDE

研究室の、使い方。

プレイから再現実験、次のAIの追加まで。

01

ルールは、1操作。

手番ごとに鏡を1枚、90°回転。/ と \ が切り替わり、共通のレーザー3台が同時に発射されます。命中したコアを操作側が獲得し、多く獲得した方が勝ちです。

両者合計30操作、または全3コア獲得で終了。引き分けもあります。鏡は移動しません。発射台に当たった光は停止します。

未獲得コアは同じ発射中は光を止め、次の操作から透明になります。複数の光線が同じコアに当たっても1得点です。

02

到達可能と、必勝は違う。

初期状態でコアに光が当たらないことと、各コアに個別に到達する合法操作列があることを検証しています。6〜200枚すべてに対応します。

相手が妨害しても取れる保証、両者が最善でも全コアを取る保証、すべての対局が面白い保証ではありません。

ランダム配置で証明手順を得られなければ、経路を組み立てた配置を使用します。配置方式は対局JSONにも記録します。

03

実験を、再現する。

同じシード・鏡枚数の盤面で、先手と後手を交換して2局対戦。AIの乱数シードも記録します。途中停止では、完了した先後ペアだけを残します。

JSONには初期盤面、全操作、計算量、Wasmのハッシュ、実験条件が入ります。読み込んでリプレイできます。時間制限モードは端末負荷で結果が変わり得ます。

04

新しいAIを、足す。

簡単に追加するなら js/extensions.js に1つのAI定義を追加。コンパイルせず、選択画面・図鑑・大会に現れます。

C++版は cpp/registry.hpp に登録してWasmを再ビルド。公開用Wasmは既に同梱しているので、今ある25体を使うためのビルドは不要です。

追加手順とテンプレート ↓

公開に必要なのは、このフォルダの中身。

index.html と一緒に style.css、script.js、js/、runtime/ をアップロードします。外部AI API・課金サービス・利用者側のC++インストールは不要です。

GitHub Pagesの公開元は main / (root)。公開フォルダ直下に index.html を置いてください。ローカルでは python -m http.server 8000 を起動して http://localhost:8000 から開きます。
