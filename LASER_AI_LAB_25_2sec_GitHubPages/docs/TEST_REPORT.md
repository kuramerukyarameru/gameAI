# 動作確認 — Edition 04 / 最大2秒

## 検証済み項目

- 公開用AI01〜AI25が登録され、合法な手を返す。
- 鏡6〜200枚、初期盤面生成、3コアの個別到達証明、レーザーの反射と得点計算。
- 2/20ms設定・100枚以外を含む計150回の意思決定。
- **2,000ms設定で25体を各1回検証**。AIにより早く終了するが、探索を続ける手法は約2,000msで打ち切り。単一判定で観測した最大は約2,000ms。厳密な割込み保証ではない。
- 18局の対局完走、入力状態不変、MinimaxとNegamaxの対応、保存データの検証。
- Chromiumブラウザで画面、先後、観戦・1手送り、鏡数変更、棋譜再生、AI解説、24局の総当たり、先後ペア集計、CSV・JSON、停止、スマホ幅の操作を検証。
- 2秒思考中に画面の別タブを操作でき、応答性を維持したことも確認。

## 実装上の注意

- 2秒は協調的な**ソフト時間予算**。WebAssembly中の長い単一処理は割り込めないため、ハードリアルタイムの厳密な上限ではない。
- 25体全員が毎手2秒考えるわけではない。固定深度探索・評価法は早く終了する。
- 探索木のメモリ容量に達したMCTSは、木をそれ以上拡張せず末端のプレイアウトを続行する。
- すべての端末・ブラウザの動作やGitHub Pagesへの実際のデプロイまでは保証しない。
- 長時間の実験では、タブを閉じる前に結果をJSON/CSVで保存すること。
