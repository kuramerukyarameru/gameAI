# 最初に読む

**このZIPの中身をすべてアップロードすれば、AI01〜AI25を使えます。初回ビルド不要です。**

1. ZIPを展開する。
2. `index.html` がある階層の中身をGitHubの公開先へ入れる。
3. `Settings → Pages → main / (root)` で公開する。
4. デプロイ成功後、Pagesに表示された「Visit site」を開く。

鏡の枚数はARENAの「鏡の枚数」で6〜200枚に変更できます。「盤面を生成」で反映。
EXPERIMENTでは `20,50,100,150,200` のように複数枚数をまとめて比較できます。

**フォルダごと置いた場合はURLにもそのフォルダ名が必要です。**
前の `gameAI/laser-ai-lab/` を使うなら、その中身を今回の中身で置き換えます。
リポジトリ直下で開きたいなら、`index.html` をリポジトリ直下に置きます。

詳しい導入方法・トラブル対処は [README.md](README.md)。
25体の解説はアプリのAGENTS画面、または [AI_GUIDE.md](docs/AI_GUIDE.md)。

**時間予算：** 初期値2秒、上限2秒。2/20/200/2000msに切替可能。 AI01〜AI25の全AIが1手最大2秒の探索打ち切り目安を共有します。厳密なOSレベルの時間保証ではありません。
